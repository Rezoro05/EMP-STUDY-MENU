# Fall Menu Study

A personal study app for a restaurant tasting menu: dishes, mise, pairings,
pronunciation, spiels, flashcards with spaced repetition, speak-it and
order-of-service practice, a quiz, and an allergy matrix.

## Use it

Open `index.html` in a browser. Everything is in that one file plus the
`img/` folder. No build step.

## Notes

- Progress, spiel edits and confirmations are saved in the browser on the
  device you use (local storage).
- Speech uses the browser's built-in voice.
- Adding your own photos and saving to an account only work in the
  version hosted on claude.ai, where this app was first built.
- Wine bottle and dining room photos are not included in this repository.
  Where a photo is missing, the app simply shows none.
- Ingredient photos are from Wikimedia Commons; see `CREDITS.md`.
- Spiels are drafts and pronunciations are guides. For a real guest
  allergy, always go by the restaurant's current sheet.
